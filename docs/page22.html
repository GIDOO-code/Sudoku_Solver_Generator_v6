Sudoku Algorithm 7

  Puzzle class(UPuzzle)

    Puzzle class
  • In GNPX (version 7 and later), there are two types of Puzzle class./li>
  • One is a class for the problem list.
    This class stores Sudoku puzzles—whether imported from a file or generated by GNPX—and is therefore a simple class consisting of only a few elements.
  • The second class is the Puzzle class(UPuzzle) used by the analysis algorithm.
    This class contains various elements required for the analysis algorithm. It is instantiated at the start of the analysis and destroyed once the analysis is complete. During the execution of the analysis algorithm, the object may also be copied. All objects created during the analysis of a single Puzzle are linked to and maintained via a root object.
    UPuzzle class
  • The first four elements—the problem ID, name, timestamp, and the comment provided during decryption (solMessage)—are all identification fields. They are not used by the analysis algorithm.
  • "DifficultyLevel" represents the difficulty of a puzzle. Note that this does not refer to the difficulty experienced by a human solver. The analysis algorithms used here frequently encounter methods that are easy for a program to identify but extremely difficult for a human to discover; the difficulty levels are assigned based on the complexity involved in these methods (using a subjective assessment of appropriateness). Generally, only puzzles up to levels 1, 2, 3, or 4 can be solved manually. Currently, the scale extends up to level 10.
  • "BOARD" is a list of 81 cells (represented by the "UCell" class) that defines the puzzle.
public class UPuzzle{
	public int     ID;
	public string  Name;
	public string  TimeStamp;
	public string  solMessage;

	public int     DifficultyLevel;    //-1:初期状態 0:手動作成
	public bool    Insoluble;    //解なし
	public List<UCell> BOARD;

	public UPuzzle( ){
		ID=-1;
		BDL = new List<UCell>();
		for( int rc=0; rc<81; rc++ ) BOARD.Add(new UCell(rc));
		this.DifficultyLevel = 0;
	}
	public UPuzzle( List<UCell> BOARD ){
		this.BOARD  =  BOARD;
		this.DifficultyLevel = 0;
	}
	public UPuzzle( int ID, List<UCell> BOARD, string Name="", int DifLvl=0 ){
		this.ID = ID;
		this.BOARD = BOARD;
		this.Name = Name;
		this.DifficultyLevel = DifLvl;
	}

	public UPuzzle Copy( ){
		UPuzzle SDP = (UPuzzle)this.MemberwiseClone();
		SDP.BOARD = new List<UCell>();
		foreach( var P in BOARD ) SDP.BOARD.Add(P.Copy());
		return SDP;
	}
}
